# Batterijpacks

Metingen en identiteit van elk batterijpack.

De functielijst van de integratie legt de Batterijpacks-entiteiten uit in [Optionele apparatuur](../../../../custom_components/saj_local/docs/features.md#optional-equipment).

58 entiteiten. Gegenereerd door `make docs`. Niet met de hand bewerken.

Een voorvoegsel dat in Configureren is ingesteld komt na `saj_` in de ID van elke Batterijpacks-entiteit, bijvoorbeeld `sensor.saj_house_battery_pack1_soc` met het voorvoegsel `house`.

# Batteriepacks

Messwerte und Identität jedes Batteriepacks.

Die Funktionsliste der Integration erklärt die Entitäten (Batteriepacks) in [Optionale Ausstattung](../../../../custom_components/saj_local/docs/features.md#optional-equipment).

58 Entitäten. Erzeugt von `make docs`. Nicht von Hand bearbeiten.

Ein in Konfigurieren gesetztes Präfix steht nach `saj_` in der ID jeder Entität (Batteriepacks), zum Beispiel `sensor.saj_house_battery_pack1_soc` mit dem Präfix `house`.

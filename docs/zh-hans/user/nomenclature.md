# 术语表

SAJ Local、仪表盘卡片和文档使用的术语，每个术语附一句话说明。集成、卡片和文档的每一种译文，对这里列出的每一件事物都只使用一个术语。集成功能列表的 [语言](../../../custom_components/saj_local/docs/features.md#languages) 一节列出了 SAJ Local 提供的语言。

## SAJ 设备与读数

| 术语 | 说明 |
| --- | --- |
| 逆变器 | SAJ 的设备，把光伏和电池的直流电转换为供家庭和电网使用的交流电。 |
| HS3 | SAJ HS3 混合逆变器型号，三相型号。 |
| H2 | SAJ H2 混合逆变器型号，单相型号。 |
| 型号 | SAJ Local 用来选择寄存器列表的逆变器类型：自动、HS3 或 H2。 |
| 自动 | 根据逆变器上报的设备类型识别型号的型号选项。 |
| 可选设备 | 安装中可有可无的设备：电池、电表 A、电表 B、充电桩或并机系统。 |
| 已安装 | 告诉 SAJ Local 某个可选设备已安装的设置。 |
| 未安装 | 告诉 SAJ Local 某个可选设备未安装的设置。 |
| 电池 | 与逆变器相连的储能装置。 |
| 电池包 | 电池中的一个电池模块，显示为“电池包”加编号。 |
| 荷电状态 | 电池的电量百分比。 |
| 备用电量 | 逆变器保留的电池电量，放电时不会低于该值。 |
| 光伏 | 光伏板发出的功率。 |
| 光伏组串 | 串联在一起并接入逆变器一路输入的一组光伏板。 |
| 相 | 交流供电的一根导线。 |
| 电网 | 家庭所连接的公共电力网络。 |
| 购电 | 从电网取电。 |
| 馈电 | 向电网送电。 |
| 充电 | 向电池输入功率。 |
| 放电 | 从电池取出功率。 |
| 家庭 | 家庭用电的功率。 |
| 备用负载 | 电网故障时，由电池和光伏板继续供电的负载。 |
| 电表 A | 可连接到逆变器的第一块电表。 |
| 电表 B | 可连接到逆变器的第二块电表。 |
| 充电桩 | 与逆变器相连的电动汽车充电桩。 |
| 并机系统 | 多台逆变器作为一个系统协同工作。 |
| 故障 | 设备上报的问题，带有寄存器和位。 |
| 清除故障 | 请求逆变器清除已上报故障的按钮。 |
| 运行状态 | 逆变器所处的状态，例如运行或待机。 |
| 模式 | 逆变器的工作模式，例如分时模式。 |
| 分时模式 | 电池在你设定的时段内充电和放电的模式。 |
| 时段 | 分时计划中用于充电、放电或充电桩的一个时间段。 |
| EMS | 逆变器的能量管理系统功能，接受来自外部的功率目标。 |
| EMS 心跳 | SAJ Local 读取 EMS 目标以保持 EMS 功能有效的间隔。 |
| EMS 超时 | 逆变器在 EMS 功能未被保持有效后结束该功能的时间。 |
| 防逆流保护 | 逆变器防止功率倒流回逆变器的保护，EMS 功能会将其关闭。 |
| 功率控制 | 让电池、电网连接或逆变器保持在设定的功率。 |
| 功率目标 | 功率控制功能所保持的功率。 |
| 计划 | 功率控制功能运行的时间。 |
| 允许控制 | 允许 Home Assistant 更改逆变器设置的设置项。 |
| 控制 | 更改逆变器设置的能力，与仅读取相对。 |
| 寄存器 | 逆变器中带编号的存储位置，保存一个读数或一项设置。 |
| 被拒绝的寄存器 | 逆变器拒绝应答的寄存器。 |
| Modbus TCP | SAJ Local 与逆变器通信所用的网络协议。 |
| 主机 | 逆变器的网络地址。 |
| 端口 | 逆变器的网络端口，默认为 502。 |
| 单元 ID | 逆变器的 Modbus 地址，范围为 1 到 247。 |
| 通信模块 | 逆变器中应答网络请求的部分。 |
| 数据块 | 用一次请求读取的一段寄存器。 |
| 实时 | 每秒都在变化的读数所在的数据块。 |
| 五分钟平均值 | 逆变器按五分钟求平均的读数所在的数据块。 |
| 电量 | 发电量和用电量读数所在的数据块，例如今日电量。 |
| 标识 | 逆变器上报的型号、序列号和版本。 |

## SAJ Local 概念

| 术语 | 说明 |
| --- | --- |
| 系统 | 添加到 Home Assistant 的一台逆变器及其设备。 |
| 安装 | 一个 SAJ Local 配置条目，即一个系统。 |
| 前缀 | 添加到某个安装的实体 ID 中的可选文字，在有多个系统时使用。 |
| 轮询 | 按一定间隔读取逆变器。 |
| 轮询组 | 一组选定的实体，SAJ Local 以快于或慢于默认间隔的频率读取。 |
| 更新间隔 | 两次读取逆变器之间的秒数，显示为“更新间隔（秒）”。 |
| 请求负载 | SAJ Local 每分钟发给逆变器的请求数，上限为 60 秒内 40 次。 |
| 预算 | 请求负载的上限。 |
| 更换型号 | 把系统迁移到新的逆变器，或在 H2 与 HS3 之间迁移，并保留历史记录。 |
| 未验证 | 手动选择、且无法与设备类型核对的型号。 |
| 诊断下载 | 保存系统隐私安全快照的文件，用于提交错误报告。 |
| 调试日志 | 写入详细日志行以便排查问题的选项。 |
| 仪表盘卡片 | SAJ Local 添加到 Home Assistant 仪表盘的卡片。 |
| 功率流卡片 | 显示光伏、电池、电网和家庭之间实时功率的卡片。 |
| 状态卡片 | 显示运行状态、模式、关键读数和故障的卡片。 |
| 故障卡片 | 列出当前故障的卡片。 |
| 电池卡片 | 显示电池读数和每个电池包一行的卡片。 |
| 控制卡片 | 显示系统共用控制项的卡片。 |
| 计划卡片 | 以一周时间线显示时段的卡片。 |
| 星期磁贴卡片功能 | 可添加到磁贴卡片的七个星期按钮。 |
| 状态徽章 | 显示运行状态和当前故障数量的徽章。 |

## Home Assistant 概念

| 术语 | 说明 |
| --- | --- |
| Home Assistant | 家庭自动化软件，SAJ Local 是它的一个集成。 |
| 集成 | 把某类设备或服务接入 Home Assistant 的软件。 |
| HACS | Home Assistant 社区商店，用于安装 SAJ Local。 |
| 自定义存储库 | 不在 HACS 默认列表中、通过地址添加到 HACS 的存储库；README 中的“HACS 自定义”徽章表明 SAJ Local 是这样的存储库。 |
| 配置流程 | 添加系统的设置对话。 |
| 配置条目 | 一个系统已保存的设置。 |
| 子条目 | 配置条目中可单独添加和更改的部分，例如轮询组或功率计划。 |
| 配置 | 集成上打开其选项的按钮。 |
| 设备与服务 | 列出集成、设备和实体的 Home Assistant 设置页面。 |
| 设置 | 用于配置 Home Assistant 的页面。 |
| 设备 | Home Assistant 中一件设备的记录，其下包含实体。每个系统是一个设备。 |
| 实体 | Home Assistant 显示的一个读数、设置或命令。 |
| 实体 ID | 实体的唯一标识符，例如 sensor.saj_pv_power。 |
| 传感器 | 显示读数的实体。 |
| 二元传感器 | 只有开或关两种状态的实体，例如故障。 |
| 数值输入器 | 保存一个可更改数值的实体。 |
| 选择 | 保存列表中一个选项的实体。 |
| 开关 | 可以打开或关闭的实体。 |
| 时间 | 保存一天中某个时刻的实体。 |
| 按钮 | 按下后执行一个操作的实体。 |
| 默认启用 | 添加系统时实体是否处于启用状态。 |
| 已禁用 | Home Assistant 不读取也不显示的实体。 |
| 修复问题 | Home Assistant 中提示需要你处理的通知，带有“修复”按钮。 |
| 仪表盘 | 由卡片组成的 Home Assistant 界面。 |
| 卡片 | 仪表盘上的一个区块。 |
| 磁贴卡片 | 显示一个实体的 Home Assistant 卡片，可添加功能。 |
| 徽章 | 仪表盘顶部徽章行中的小项目。 |
| 自动化 | 在某件事发生时让 Home Assistant 执行操作的规则。 |
| 辅助元素 | 你自己创建的 Home Assistant 实体，例如计划表辅助元素。 |
| 区域 | 设备所归入的房间或地点。 |
| 主题 | Home Assistant 界面的颜色。 |
| 语言 | Home Assistant 用户在个人资料页面选择的语言。 |
| 重新加载 | 在不重启 Home Assistant 的情况下重启一个集成。 |
| 重启 | 重启 Home Assistant。 |
| 开发者工具 | 用于检查状态和调用操作的 Home Assistant 页面。 |
| 日志 | Home Assistant 的消息记录。 |

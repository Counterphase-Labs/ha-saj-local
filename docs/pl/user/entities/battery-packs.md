# Moduły baterii

Odczyty i tożsamość każdego modułu baterii.

Lista funkcji integracji wyjaśnia encje obszaru Moduły baterii w [Wyposażenie opcjonalne](../../../../custom_components/saj_local/docs/features.md#optional-equipment).

Liczba encji: 58. Wygenerowano poleceniem `make docs`. Nie edytuj ręcznie.

Prefiks ustawiony w Skonfiguruj trafia po `saj_` w ID każdej encji: Moduły baterii, na przykład `sensor.saj_house_battery_pack1_soc` z prefiksem `house`.

# 仪表盘卡片

“仪表盘卡片”页面说明如何把 SAJ Local 卡片添加到仪表盘并选择系统，并列出每个元素显示什么。完整列表见卡片功能列表的 [元素与设置](../../../../frontend/docs/features.md#elements-and-setup) 和 [主题与语言](../../../../frontend/docs/features.md#theme-and-language) 两节，以及集成功能列表的 [卡片](../../../../custom_components/saj_local/docs/features.md#cards) 一节。

SAJ Local 提供这些卡片，并在 Home Assistant 启动时把这些卡片注册到 Home Assistant。这些卡片会出现在卡片选择器中，因此无需添加资源，也无需清除缓存。

## 元素

| 元素 | 该元素显示什么 |
| --- | --- |
| [功率流卡片](power-flow-card.md) | 光伏、电池、电网、家庭和可选设备之间的实时功率。 |
| [状态卡片](status-card.md) | 运行状态、应用模式、关键读数、今日电量、故障汇总，以及是否允许控制。 |
| [故障卡片](faults-card.md) | 每台设备的当前故障，以及“清除故障”按钮。 |
| [电池卡片](battery-card.md) | 标出限值的荷电状态、电池读数，以及每个电池包一组行。 |
| [控制卡片](controls-card.md) | 系统的设置，分区显示。 |
| [计划卡片](schedule-card.md) | 充电、放电和充电桩时段、一周时间线和时段编辑器。 |
| [星期磁贴卡片功能](weekdays-feature.md) | 磁贴卡片上的七个星期按钮，用于设置时段的星期。 |
| [状态徽章](status-badge.md) | 显示运行状态和有当前故障的设备数量的徽章。 |

## 添加元素

1. 编辑仪表盘并选择“添加卡片”。对于星期功能，请添加一张磁贴卡片并打开该磁贴卡片的功能。对于徽章，请编辑仪表盘的徽章。
2. 在选择器中选取 SAJ Local 元素。这六张卡片显示实时预览。
3. 在可视化编辑器的“系统”字段中选择系统。新的卡片或徽章从第一个系统开始。星期功能没有编辑器，因为该功能使用磁贴卡片的实体。

有两个系统的家庭，每个系统各添加一次卡片。卡片的标题是系统的设备名称加上型号，例如 SAJ HS3 (12000 W)。只有当两个系统的标题本来会完全相同时，SAJ Local 才会加上序列号。如果你想要其他标题，请在 Home Assistant 中重命名每个设备。

这些元素通过实体注册表而不是通过实体 ID 查找系统的实体，因此当你更改[前缀](../entities-and-prefix.md#前缀)时，这些元素仍然继续工作。

## 每个元素的共同行为

- **只显示系统具备的内容。** 其实体不存在或已禁用的部分不会被绘制，因此每张卡片只显示系统具备的内容。只属于某一个型号的部分只出现在该型号上，每个元素页面都会指出这些部分。
- **空卡片会说明原因。** 如果卡片的实体一个都没有启用，卡片会说明要启用哪种实体，并附带指向系统设备页面的链接。
- **不应答的系统。** 卡片会说明这一点，并把数值变暗。
- **点按数值。** 点按数值会在 Home Assistant 中打开该实体的详细信息。
- **锁定的控件。** 当系统的[允许控制](../changing-settings.md#允许控制)关闭时，每个控件都被禁用，并且一个锁链接到集成的设置。开启“允许控制”也会启用卡片所需的实体，参见[控制项集合](../changing-settings.md#控制项集合)。
- **每次决定更改一次。** 滑块在你松开滑块时更改逆变器。数字字段在按回车键或离开该字段时更改逆变器。列表、开关或时间字段在发生变化时更改逆变器。随后控件显示逆变器所保存的值，被拒绝的更改会以集成的措辞显示在控件下方。

## 主题和语言

这些元素跟随 Home Assistant 主题。实体名称、数值和状态使用 Home Assistant 的格式和语言。卡片的文字提供英语、德语、荷兰语、法语、简体中文、西班牙语、意大利语、波兰语和瑞典语版本。使用其他任何语言的仪表盘，卡片的文字显示为英语。

## 尚不支持

- 上述九种语言以外的其他语言的卡片文字。

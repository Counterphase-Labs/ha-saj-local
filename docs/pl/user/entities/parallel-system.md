# System równoległy

Odczyty równoległego systemu maszyn.

Lista funkcji integracji wyjaśnia encje obszaru System równoległy w [Wyposażenie opcjonalne](../../../../custom_components/saj_local/docs/features.md#optional-equipment).

Liczba encji: 63. Wygenerowano poleceniem `make docs`. Nie edytuj ręcznie.

Prefiks ustawiony w Skonfiguruj trafia po `saj_` w ID każdej encji: System równoległy, na przykład `sensor.saj_house_parallel_id` z prefiksem `house`.

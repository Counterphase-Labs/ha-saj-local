# Entità

Ogni entità che SAJ Local può creare, una pagina per ogni area. La sezione [Dispositivi ed entità](../../../../custom_components/saj_local/docs/features.md#devices-and-entities) dell'elenco delle funzionalità dell'integrazione descrive i tipi di entità, quali entità sono abilitate per impostazione predefinita e il segno delle letture di potenza.

Un sistema riceve solo le entità adatte al suo modello, alle sue apparecchiature installate e al suo numero di fasi, stringhe solari e moduli batteria. La colonna Modelli indica quali modelli hanno un'entità, e la colonna Apparecchiature e quantità indica che cosa deve essere installato.

# 设备故障和修复问题

“设备故障和修复问题”页面说明 SAJ Local 如何显示逆变器、电池和充电桩上报的故障，以及 SAJ Local 在 Home Assistant 中提出哪些修复问题。故障行为的完整列表见集成功能列表的 [设备故障和修复问题](../../../custom_components/saj_local/docs/features.md#device-faults-and-repairs) 一节。每个故障实体都在实体参考的[故障实体](entities/faults.md)中。

设备故障和修复问题是分开的。设备故障是一个实体，报告设备所说的情况。修复问题是 SAJ Local 与设备的连接出现的问题，或 SAJ Local 的设置出现的问题，Home Assistant 在“设置”和“修复”下列出该问题。

## 设备故障

逆变器、电池和充电桩的每一个具名故障都是设备类别为“问题”的二元传感器，默认启用。故障有历史记录，并且可以触发自动化。

- **汇总：** 逆变器、电池和充电桩各有一个汇总故障，例如“逆变器故障”，设备上报任何内容时该故障为开。
- **未识别：** 每台设备还有一个未识别的故障，当逆变器置位某个没有文档说明含义的位时该故障为开。[诊断下载](troubleshooting.md#下载诊断)列出该寄存器和该位，因此你可以报告该位。
- **每个型号上的实体 ID 相同：** 一个故障在每个上报该故障的型号上都有同一个实体 ID。某个型号不上报的故障在该型号上没有实体。
- **电池包：** 每个电池包有一个故障实体和一个警告实体。HS3 有一个电池包。H2 最多有四个。
- **未安装的设备：** 电池故障只在安装了电池时存在，充电桩故障只在安装了充电桩时存在。参见[可选设备](optional-equipment.md)。
- **无法读取的故障寄存器：** 依赖该寄存器的故障不可用。SAJ Local 不做猜测。
- **日志：** 故障变为开时，会记录一条警告，指出系统和故障。故障清除时，SAJ Local 记录一条信息行。

[故障卡片](cards/faults-card.md)在仪表盘上列出系统的当前故障，以及每个故障开始了多久。该卡片的“清除故障”按钮发送“清除当前故障”命令，该命令需要[允许控制](changing-settings.md#允许控制)。

## 修复问题

SAJ Local 针对你可以处理的情况提出修复问题。

| 修复问题 | 提出的时机 | 你可以做什么 |
| --- | --- | --- |
| 系统的型号设置错误 | 该地址上的逆变器识别为另一个型号，而不是所选型号。 | 修复会采用 SAJ Local 发现的型号。参见[更换逆变器](replacing-the-inverter.md)。 |
| 系统现在连接到另一台逆变器 | 该地址上的逆变器序列号不同。 | 修复会采用新的逆变器。参见[更换逆变器](replacing-the-inverter.md)。 |
| 系统连接到未识别的设备 | 设备类型不是已识别的型号。 | 在“配置”中选择型号。SAJ Local 随后将该型号作为未验证使用。 |
| 系统有逆变器拒绝的读数 | 逆变器连续三次拒绝这些读数。 | 修复会禁用所列实体，因此 SAJ Local 不再读取这些实体。参见[保护逆变器](protecting-the-inverter.md#逆变器拒绝某个读数时)。 |
| 系统已停止应答 | 逆变器已有 15 分钟没有应答。 | 检查电源、网络和其他 Modbus 客户端。第一次成功读取后，该问题会消失。 |
| 不再检测到设备 | SAJ Local 以前检测到的设备现在不再被检测到。 | 检查该设备，或在“配置”中把该设备设为“未安装”。参见[可选设备](optional-equipment.md#已记住的设备不再被检测到时)。 |

![Home Assistant 中的一个修复问题，内容为 SAJ HS3MOCK000000000003 有逆变器拒绝的读数](../../images/zh-hans/faults-and-repairs-repair-issue.png)

前三个问题是型号问题。一个系统同一时间只有一个型号问题处于打开状态，并且在有型号问题打开时，不会提出系统已停止应答的问题。

当修复问题的条件结束，或你移除系统时，该修复问题会消失。关于被拒绝读数的问题在你禁用所列的某个实体时也会消失。

## 尚不支持

- 针对设备故障的修复问题。设备故障是实体，集成不会针对故障提出修复问题。

# Entidades

Todas las entidades que SAJ Local puede crear, una página por área. La sección [Dispositivos y entidades](../../../../custom_components/saj_local/docs/features.md#devices-and-entities) de la lista de funciones de la integración explica los tipos de entidad, qué entidades están habilitadas por defecto y el signo de las lecturas de potencia.

Un sistema recibe solo las entidades que encajan con su modelo, su equipo instalado y su número de fases, strings solares y módulos de batería. La columna Modelos indica qué modelos tienen una entidad, y la columna Equipo y números indica qué debe estar instalado.

# Entiteiten

Elke entiteit die SAJ Local kan aanmaken, één pagina per gebied. De sectie [Apparaten en entiteiten](../../../../custom_components/saj_local/docs/features.md#devices-and-entities) van de functielijst van de integratie legt de entiteitstypen uit, welke entiteiten standaard zijn ingeschakeld en het teken van vermogensmetingen.

Een systeem krijgt alleen de entiteiten die passen bij zijn model, zijn geïnstalleerde apparatuur en zijn aantal fasen, zonnestrings en batterijpacks. De kolom Modellen zegt welke modellen een entiteit hebben, en de kolom Apparatuur en aantallen zegt wat geïnstalleerd moet zijn.

Gegenereerd door `make docs`. Niet met de hand bewerken.

# Faults

Faults the inverter, the battery and the EV charger report.

The integration feature list explains the Faults entities in [Device faults and repairs](../../../../custom_components/saj_local/docs/features.md#device-faults-and-repairs).

139 entities. Generated by `make docs`. Do not edit by hand.

A prefix set in Configure goes after `saj_` in the ID of every Faults entity, for example `binary_sensor.saj_house_battery_pack1_fault` with the prefix `house`.

# Settings

Settings and commands that change the inverter.

The integration feature list explains the Settings entities in [Changing settings](../../../../custom_components/saj_local/docs/features.md#changing-settings).

22 entities. Generated by `make docs`. Do not edit by hand.

A prefix set in Configure goes after `saj_` in the ID of every Settings entity, for example `number.saj_house_passive_mode` with the prefix `house`.

# 保护逆变器

“保护逆变器”页面列出 SAJ Local 对其发送的一切内容所设的限制，使逆变器的通信模块能持续为 Home Assistant 服务。通信模块可能不再为轮询过于频繁的客户端服务，因此没有任何设置可以取消限制。完整列表见集成功能列表的 [保护逆变器](../../../custom_components/saj_local/docs/features.md#protecting-the-inverter) 一节。

## 限制

- **一个连接，一次一个请求。** SAJ Local 对一台逆变器只打开一个连接，等待每个应答后才发送下一个请求，请求之间有短暂停顿。
- **任意 60 秒内最多 40 次请求。** 该限制按逆变器地址计算。SAJ Local 跨重新加载计数，因此重新加载、设置重试或连接检查都不会超出限制。超出限制的请求会等待。
- **相邻的寄存器共用一次请求。** SAJ Local 把位置相近的寄存器放在一次请求中读取，绝不会超出型号文档规定的数据块。一次请求在 HS3 上不会超过 32 个寄存器，在 H2 上不会超过 56 个。把位置相邻的实体归为一组开销更小，参见[轮询](polling.md)。
- **一个周期内不重试。** 读取失败后，下一次尝试前的等待时间从最短间隔开始翻倍，最长 5 分钟。该等待在重新加载后依然有效。第一个成功的周期会重新读取全部内容。
- **每次等待都有时间限制。** 停滞的逆变器会使一个周期以失败告终，但不会停止轮询。迟到的或无关的应答会被丢弃。
- **关闭的连接只重新打开一次。** 该周期随后会再次读取每个已启用的实体，因此没有任何值比重新连接更旧。
- **60 秒内最多 20 次更改。** 参见[更改设置](changing-settings.md#更改后会发生什么)。超出限制的更改会被拒绝，不会排队。

## 逆变器拒绝某个读数时

拒绝是一种应答，而不是故障。只有被拒绝请求中的实体变为不可用，其他实体继续更新。

1. SAJ Local 在接下来的几个周期中把被拒绝的请求对半拆分，直到找到被拒绝的实体。
2. 连续三次被拒绝的实体会被暂停。该实体显示为不可用，并且不再被读取。
3. SAJ Local 每天以及每次集成加载时，都会再次尝试已暂停的实体。当该寄存器应答时，该实体恢复。
4. 一个修复问题会列出已暂停的实体。该问题的修复会禁用这些实体，因此 SAJ Local 从此不再读取这些实体。参见[故障和修复](faults-and-repairs.md#修复问题)。

## 逆变器不再应答时

当逆变器已有 15 分钟没有应答时，会有一个修复问题说明这一点。第一次成功读取后，该问题会消失。请检查逆变器和通信模块的电源、网络，以及是否没有其他 Modbus 客户端占用连接。

## 尚不支持

- 更改限制。这些限制用来保护逆变器，因此没有任何设置可以提高限制。

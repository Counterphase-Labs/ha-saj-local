# Added by the integration

Entities the integration adds outside the register catalogue.

The integration feature list explains the Added by the integration entities in [Changing settings](../../../../custom_components/saj_local/docs/features.md#changing-settings) and [Power control](../../../../custom_components/saj_local/docs/features.md#power-control).

7 entities. Generated by `make docs`. Do not edit by hand.

A prefix set in Configure goes after `saj_` in the ID of every Added by the integration entity, for example `binary_sensor.saj_house_control_allowed` with the prefix `house`.

| Name | Entity ID | Type | Unit | Models | Equipment and counts | Enabled by default |
| --- | --- | --- | --- | --- | --- | --- |
| Control allowed | `binary_sensor.saj_control_allowed` | Binary sensor | - | HS3, H2 | - | Yes |
| Battery power control | `switch.saj_battery_power_control` | Switch | - | HS3, H2 | Battery | No |
| Battery power target | `number.saj_battery_power_target` | Number | W | HS3, H2 | Battery | No |
| Grid power control | `switch.saj_grid_power_control` | Switch | - | HS3 | Meter A | No |
| Grid power target | `number.saj_grid_power_target` | Number | W | HS3 | Meter A | No |
| Inverter power control | `switch.saj_inverter_power_control` | Switch | - | HS3 | - | No |
| Inverter power target | `number.saj_inverter_power_target` | Number | W | HS3 | - | No |

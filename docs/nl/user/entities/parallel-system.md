# Parallel systeem

De metingen van een parallel machinesysteem.

De functielijst van de integratie legt de Parallel systeem-entiteiten uit in [Optionele apparatuur](../../../../custom_components/saj_local/docs/features.md#optional-equipment).

63 entiteiten. Gegenereerd door `make docs`. Niet met de hand bewerken.

Een voorvoegsel dat in Configureren is ingesteld komt na `saj_` in de ID van elke Parallel systeem-entiteit, bijvoorbeeld `sensor.saj_house_parallel_id` met het voorvoegsel `house`.
